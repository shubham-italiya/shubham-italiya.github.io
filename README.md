# shubham-italiya.github.io

My portfolio website: plain HTML, CSS and a few lines of JavaScript, no framework.

`index.html` is generated from [`cv.toml`](cv.toml) by [`build.py`](build.py), so the site and my CV always
show the same facts:

```bash
python3 build.py   # standard library only
```

Served by GitHub Pages from the `main` branch.
